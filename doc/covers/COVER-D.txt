Subject: [PATCH 0/6] MP4 ac-4+dac4 support + AC-4 parser

Last series: MP4 carriage for AC-4 plus the frame parser both
carriages need. Posts after Series C (needs the encoder DSI-extradata
contract: raw DSI bytes as extradata, packed per ETSI 103 190-2 E.5,
empty = hard error). Order inside the series is parser-first: MP4
demux sets need_parsing = HEADERS, which is dead without a registered
parser, and the TS demux tags already in-tree need only the splitter.

Patches:
  [PATCH 1/6] avcodec: add ff_ac4_parser
    ParseContext + combine_frame split loop (AC40/41 sync scan,
    ext-len, AC41 CRC-16, chain-anchor + TOC-head gate, 1-byte
    resync, COMPLETE_FRAMES passthrough for bare carriage); TOC
    head+bed walk (bail-untouched); duration/rate/channel/bitrate
    outputs. configure selects for the ac4 demuxer.
  [PATCH 2/6] avformat/mov: add AC-4 dac4 box support
    mov_read_dac4 (opaque DSI extradata, v1 no DSI-derived layout),
    parse-table entry, HEADERS need_parsing. Truncated dac4 ->
    INVALIDDATA, no over-read.
  [PATCH 3/6] avformat/movenc: add AC-4 ac-4/dac4 muxing support
    mp4 tag entry, mov_write_dac4_tag (verbatim DSI, EINVAL on
    empty), stsd arms. 1 packet = 1 sample; no mux-queue/drain
    hooks, no delay_moov, no btrt v1.
  [PATCH 4/6] fate: add self-contained ac4 parser tests
    api-ac4-parser-test builds vectors in code (no samples):
    split/resync over noise/lookalike/CRC-corrupt/truncated/ext-len/
    rate-gated shapes, single-at-EOF emits, bounded false-lock
    re-lock, COMPLETE_FRAMES passthrough, each in whole/13-byte/
    1-byte feeds + 5 synth sub-variants. Wired as fate-ac4-parser.
  [PATCH 5/6] fate: add self-contained ac4 mp4 mux/demux roundtrip
  test
    api-ac4-mp4-roundtrip-test synthesizes bare/AC40/AC41/ext-len
    vectors in code (no samples): mux to MP4, demux back, dac4
    byte-exact at box + extradata level, stsz == 4, byte-identical
    payloads, post-parse 48k stereo. 3 loud negatives (mux-noext
    EINVAL, trunc-dac4 + shrink-size INVALIDDATA). Wired as
    fate-ac4-mp4-roundtrip. Closes REVIEW-DMUX M1 + REVIEW-DDEMUX M1.
  [PATCH 6/6] fate: add self-contained ac4 ts demux test
    api-ac4-ts-demux-test synthesizes Annex G AC41 vectors in code
    (no samples, no encoder): mux to MPEG-TS, assert file-level
    framing/descriptors + demux-level params/payloads, 2 loud
    negatives (bad-PMT, mid-PES trunc). Wired as fate-ac4-ts-demux.

Deferred by design (P4 DEFER-OK): no shared ac4_header.h in this
series -- the mux strip stays a local ~23-line framing parse
(aacdec.c precedent) and the A0-peek/parser dual TOC walk unifies
after Series A lands (third reader); MP4 demux keeps dac4 opaque
(AAC-esds model); ac4_decoder_select + the ac4d_feed 2-byte sniff
ride Series A; TS param-fill FATE rides a Series-E follow-up.
Feed-shape contract decided: demuxers/muxers emit bare or
shape-preserved frames, the decoder sniffs the first 2 bytes.
